### <a name="_qmphm5d6rvi3"></a>**Решение**

Context diagram: ![context](context_diagram.jpg)

Container diagramm: ![container](container_diagram.jpg)

В каждом кол-центре есть очередь звонков и в случае перегрузки кол-центра автоответчик говорит о размере очереди и предлагает обратиться в партнерский кол-центр. Так как нет возможности получать информацию по процентным ставкам через API, то доступ осуществляется по SFTP к DMZ. Для того, чтобы сервис процентных ставок не выложил в DMZ какую-либо персональную информацию из внутреннего контура АБС, что может присутствовать в файле, то этот сервис читает загружаемый excel file сотрудником бэк офиса и извлекает информацию из файла по заданному шаблону, а затем формирует excel file и загружает в DMZ по SFTP.
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Альтернативы: 
- Отправлять файл по почте всем сотрудникам бэк офиса.
- Использовать google docs.


**Недостатки, ограничения, риски**

- Нужно будет поддерживать в актуальном состоянии список пользователей, кому отправлять файл.
- Использование открытых сервисов, таких как google docs - не безопасно и тяжело (невозможно) будет согласовать это решение со специалистом информационной безопасности.
